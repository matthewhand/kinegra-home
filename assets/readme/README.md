# Walkthrough captures and attribution

The walkthroughs are staged, silent screenshot animations. Home/chooser frames are from 0.9.16; live Split View/control frames are from 0.9.14. Chapter captions name their capture version. Crossfades and timing are presentation edits, not continuous input or performance evidence.

The generic demonstration uses Kinegra Omega Prime and NVIDIA's public SHIELD product page in TV Bro. No account feed, live camera/home image, private URL or audio is included. The retained source images were inspected; animations use those sources and their crossfades.
