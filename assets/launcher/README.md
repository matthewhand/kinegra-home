# Launcher artwork

`banner-kinegra-home.svg` is the editable source for the 320 × 180 Kinegra Home launcher banner. `banner-kinegra-home-320x180.png` is the image packaged by the Android build. `icon-512.png` is the original illustrated app icon.

Original project artwork uses [MIT](../../LICENSE). These are Kinegra Home assets, not official NVIDIA artwork. The separate repository banner and its provenance are under [docs/branding](../../docs/branding/README.md).
