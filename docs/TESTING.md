# Validation and support scope

0.9.24 adds an inline status and Android-settings shortcut when session shortcuts are disabled. It matches only this package’s exact accessibility component and also checks Android’s global accessibility setting. It never grants access automatically. Eleven focused policy checks cover abbreviated/full component names, multiple services, unavailable settings, lookalike components and honest captions; the unsigned build also runs its existing Java and window-broker checks.

The owner confirmed physical Back-hold worked again in 0.9.23 after re-enabling the service. That is separate from this update: 0.9.24 has not been installed or physically accepted. The previous 0.9.23 build, recovery fixtures and earlier muted pane/recovery tests remain the baseline.

Display fixtures cover narrow/portrait, standard-TV and ultrawide dimensions. Development uses an original SHIELD on Android 11 and an ultrawide display. Physical portrait/16:9, touch behavior, long sessions, firmware/DRM breadth and PiP compatibility remain open. A source beta does not imply universal Android TV compatibility.

Bug reports should include versions, input device, layout and steps. Performance reports should state duration, display refresh and observed frame/memory/lifecycle behavior. Do not post personalized app content or opaque access URLs.
